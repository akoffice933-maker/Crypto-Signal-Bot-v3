## ✅ ВСЁ ГОТОВО! Осталось 3 шага:

---

## **ШАГ 1: Откройте PowerShell**

1. Нажмите `Win + X`
2. Выберите **Windows PowerShell (Admin)**
3. Или найдите в поиске: `PowerShell` → Запуск от имени администратора

---

## **ШАГ 2: Запустите загрузку**

**Выполните команду:**

```powershell
cd d:\bot_final\deploy
.\upload-to-vps.ps1
```

**Если ошибка - разрешите скрипты:**
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

**Затем снова:**
```powershell
.\upload-to-vps.ps1
```

---

## **ШАГ 3: Подключитесь к VPS и запустите**

**1. Откройте командную строку или PowerShell:**

**2. Подключитесь к VPS:**
```bash
ssh root@148.222.186.16
```

**Введите пароль:** `6A0nZceRZE`
*(пароль не отображается при вводе - это нормально)*

**3. Запустите развёртывание:**
```bash
sudo bash /tmp/crypto-bot-source/deploy/deploy.sh
```

**4. Дождитесь завершения (2-3 минуты)**

**5. Проверьте статус:**
```bash
systemctl status crypto-bot
```

**Должно быть:** `active (running)`
