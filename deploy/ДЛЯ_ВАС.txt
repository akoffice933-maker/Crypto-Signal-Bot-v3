# 🚀 ИНСТРУКЦИЯ ПО ЗАГРУЗКЕ НА VPS

## 📋 ЧТО Я СОЗДАЛ:

В папке `d:\bot_final\deploy\` находятся:

1. **deploy.sh** - Скрипт автоматического развёртывания на VPS
2. **upload-to-vps.ps1** - Загрузка файлов на VPS (PowerShell)
3. **docker-compose-vps.yml** - Docker версия
4. **nginx.conf** - Настройка Nginx
5. **README.md** - Полная документация
6. **vps-config.env** - Ваш конфиг (заполните!)

---

## ⚡ БЫСТРЫЙ СТАРТ (3 шага):

### **ШАГ 1: Заполните конфиг**

Откройте файл `vps-config.env` и заполните:

```bash
VPS_IP=ваш_ip_адрес
VPS_PASSWORD=ваш_пароль
DOMAIN=ваш-домен.com (если есть)
EMAIL=ваш@email.com
```

**Сохраните!**

---

### **ШАГ 2: Загрузите файлы на VPS**

**Вариант A: Автоматически (PowerShell):**

1. Откройте PowerShell от имени администратора
2. Выполните:
```powershell
cd d:\bot_final\deploy
.\upload-to-vps.ps1
```

**Вариант B: Вручную (WinSCP):**

1. Скачайте WinSCP: https://winscp.net
2. Подключитесь к VPS:
   - Host: ваш VPS IP
   - Username: root
   - Password: ваш пароль
3. Скопируйте папку `bot_final` в `/tmp/crypto-bot-source`

---

### **ШАГ 3: Запустите на VPS**

**1. Подключитесь к VPS:**
```bash
ssh root@ваш-ip
```

**2. Запустите развёртывание:**
```bash
sudo bash /tmp/crypto-bot-source/deploy/deploy.sh
```

**3. Настройте .env:**
```bash
nano /opt/crypto-bot/.env
# Заполните вашими данными
# Ctrl+O, Enter, Ctrl+X для сохранения
```

**4. Перезапустите бота:**
```bash
systemctl restart crypto-bot
```

**5. Проверьте:**
```bash
systemctl status crypto-bot
```


```bash

```

