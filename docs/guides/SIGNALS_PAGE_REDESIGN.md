## ⚠️ Возможные проблемы

### 1. Страница не загружается

**Причина:** signals.html не загружен  
**Решение:**
```bash
scp -P 2222 web/static/signals.html root@148.222.186.16:/opt/crypto-bot/web/static/
```

### 2. "No signals found"

**Причина:** Нет сигналов в БД  
**Решение:** Это нормально в выходные. Проверить в понедельник.

### 3. Export CSV не работает

**Причина:** Endpoint не доступен  
**Решение:** Проверить `/signals/export.csv` вручную
