## 🚀 Пошаговая инструкция

### **Шаг 1: Создайте Telegram канал**

1. **Откройте Telegram**
2. **Меню** → **Создать канал** (New Channel)
3. **Заполните:**
   - **Название:** `Crypto Signals | BTCUSDT`
   - **Описание:**
     ```
     🤖 Автоматические сигналы для BTCUSDT Futures
     
     📊 Стратегии:
     • Liquidity Sweep Reversal
     • Volatility Breakout
     
     ⚡️ Анализ каждые 15 минут
     🎯 Confidence Score ≥ 65%
     📈 RR ≥ 2.0
     
     Bot: @Akoffice_bot
     ```
   - **Тип:** **Публичный** (Public)
   - **Ссылка:** `tCryptoSignalsBTC` (или другая свободная)
4. **Нажмите "Создать"**

### **Шаг 2: Добавьте бота как администратора**

1. **Откройте канал** → **Настройки** (иконка канала)
2. **Администраторы** → **Добавить**
3. **Найдите:** `@Akoffice_bot`
4. **Разрешения:**
   ```
   ✅ Публикация сообщений
   ✅ Редактирование сообщений
   ✅ Удаление сообщений
   ✅ Закрепление сообщений
   ❌ Добавление участников (не нужно)
   ❌ Изменение информации (не нужно)
   ```
5. **Сохранить**

### **Шаг 3: Узнайте ID канала**

**Способ 1: Через @GetMyBotIdBot (простой)**

1. Отправьте `/start` боту `@GetMyBotIdBot`
2. Перешлите любое сообщение из вашего канала
3. Бот ответит: `ID: -1001234567890`

**Способ 2: Через Telegram Web**

1. Откройте https://web.telegram.org
2. Откройте ваш канал
3. Посмотрите на URL:
   ```
   https://web.telegram.org/k/#-1001234567890
                                    ↑
                              Это ID канала
   ```

**Способ 3: Через API**

```bash
curl "https://api.telegram.org/bot<YOUR_TOKEN>/getUpdates"
```

В ответе найдите `"chat":{"id":-1001234567890,...}`

### **Шаг 4: Обновите `.env`**

```bash
cd /opt/crypto-bot
nano .env
```

**Заполните:**
```env
TELEGRAM_BOT_TOKEN=your_telegram_bot_token
TELEGRAM_CHAT_ID=-1001234567890
TELEGRAM_CHANNEL_LINK=https://t.me/CryptoSignalsBTC
```

**Важно:**
- `TELEGRAM_CHAT_ID` должен начинаться с `-100`
- `TELEGRAM_CHANNEL_LINK` — полная ссылка на канал

### **Шаг 5: Перезапустите бота**

**Docker:**
```bash
cd /opt/crypto-bot
docker-compose restart
docker-compose logs -f
```

**Python:**
```bash
sudo systemctl restart crypto-bot
sudo journalctl -u crypto-bot -f
```

### **Шаг 6: Проверьте работу**

**1. Отправьте команду боту:**
```
/start
```

**Бот должен ответить:**
```
🤖 **Bot is online**

Mode: `testnet`
Symbol: `BTCUSDT`
Signals chat: `-1001234567890`

📢 **Наш канал:** [https://t.me/CryptoSignalsBTC](https://t.me/CryptoSignalsBTC)

**Commands:**
/status - show notifier status
/signals - last 5 signals
/stats - 24h statistics
/help - bot help
```

**2. Проверьте команду `/join`:**
```
/join
```

**Бот ответит:**
```
📢 **Присоединяйтесь к нашему каналу!**

Там публикуются все сигналы в реальном времени.

🔗 **Ссылка:** https://t.me/CryptoSignalsBTC

Или нажмите: https://t.me/CryptoSignalsBTC
```

**3. Проверьте канал:**
- Откройте канал
- Бот должен отправить сообщение о запуске

## 🆘 Troubleshooting

### **Бот не публикует в канал**

**Проверьте:**
1. Бот добавлен как администратор?
2. Правильный ли ID канала (начинается с `-100`)?
3. Есть ли у бота разрешение на публикацию?

**Решение:**
```bash
# Перезапустите бота
docker-compose restart
# ИЛИ
sudo systemctl restart crypto-bot
```

### **Ошибка "Chat not found"**

**Проверьте ID:**
```bash
# В .env должно быть:
TELEGRAM_CHAT_ID=-1001234567890
```

### **Сообщения не доходят**

**Проверьте логи:**
```bash
docker-compose logs -f | grep -i telegram
# ИЛИ
sudo journalctl -u crypto-bot -f | grep -i telegram
```
